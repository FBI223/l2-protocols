# 802.1X

## What this folder is about
This folder contains notes and materials for **IEEE 802.1X port-based network access control**, including EAP over LAN (EAPOL) authentication flow commonly integrated with RADIUS-based access stacks.

## Standards covered
- **IEEE 802.1X** (Port-Based Network Access Control / EAPOL)
