# STP / RSTP

## What this folder is about
This folder contains notes and materials for **Spanning Tree Protocol (STP)** and **Rapid Spanning Tree Protocol (RSTP)** used to prevent Layer 2 switching loops in bridged Ethernet networks.

## Standards covered
- **IEEE 802.1D** (STP)
- **IEEE 802.1w** (RSTP)

## Language
- **English** (documentation)
